# 설계 결정

기준은 2026-10-04 설계 회의 메모(본문 기준일 2026-10-05)입니다. 기존 자료의 Candidate Ranking → Top-K → Future Rollout 구조를 유지하고, 학습 표적 생성과 점수 정의를 회의의 요구사항에 맞춰 확장했습니다. 0.3.0의 안내문 대조와 보완 범위는 [미션 요구사항 검토](MISSION_REVIEW.md)를 참조하세요.

| 회의 내용 | 구현 결정 |
|---|---|
| Teacher는 유효 후보 전체의 미래를 평가 | 현재 후보를 8개로 자르지 않고 생성된 유효 후보 전체에 동일 표본 Rollout 수행 |
| 실시간은 AI Ranking 후 Top-K 상세 탐색 | 115차원 관측/후보 특징 → NumPy MLP → Top-K → 공통 미래 재평가 |
| Safety First 이후 효율 우선 | 지지·CoG·하중의 최소 안전 지표를 사용. 목표 미달에서 안전을 우선하고 충족 후 보상 포화 |
| 현재 부피만으로 공간 평가하지 않음 | 연속 빈 바닥, 단편화, 높이 편차, 미관측 SKU의 footprint 배치 가능성 결합 |
| Future Value 평균과 하방 위험 분리 | 평균 적재/추가 부피와 하위 꼬리 평균·차단 비율을 별도 학습·기록 |
| 고정 가중치를 처음부터 확정하지 않음 | 초기값 → Dirichlet/CEM 반복 탐색 → 에피소드 KPI 선택 → ±20% 민감도 → Pareto → 미사용 그룹 시험 |
| 입고 순서는 모르고 수량·종류는 앎 | 확인된 preview 접두부는 보존하고 미관측 재고만 순서를 샘플링. oracle는 입력 금지 |
| 최소 6종 미래 가정 | 랜덤, 큰 박스 후반, 무거운 박스 후반, 작은 박스 우선, SKU 군집, 크기 교차 단편화 스트레스 |
| 일반 선반과 NG 분리 | 정상 보관은 `BUFFER_CURRENT`, 손상 분기는 `ROUTE_NG` |
| PPO는 필수 1차 구성요소가 아님 | Ranking/가중치 학습 먼저 제공. 선반 입출고·팔레트 종료는 규칙 행동으로 연결 |
| 로봇 feasibility와 packing mask 분리 | packing 마스크 유지, 외부 로봇 검사 왕복 계약과 검증 전 실행 차단 제공 |

신경망만으로 최종 좌표를 바로 정하는 방식은 사용하지 않습니다. 작은 신경망이 후보의 미래 결과를 예측하므로 입력 상태에 따라 순위가 바뀌고, 가중치가 바뀌어도 결과 벡터를 다시 조합할 수 있습니다. 상세 탐색은 마지막에 같은 평가기로 확인합니다. 모델이 없거나 지정된 OOD이면 유효 후보 전체를 탐색합니다.

가중치는 여섯 항목 `space`, `future_fit`, `future_volume`, `risk`, `balance`, `handling`입니다. 앞의 세 항목과 균형은 보상, 위험·취급 시간은 비용입니다. 합을 1로 정규화하지만 안전 기준을 낮춰 고득점하도록 학습하지 않습니다. 초기 기준과 학습된 값을 별도로 보관합니다.

가중치 선택 목적은 `평균 적재율 + 0.2 × 평균 성공률 + 0.1 × 적재율 10% 분위수`입니다. 마스크 위반이나 음의 하중 여유가 있으면 해당 설정을 제외합니다. `cvar_fraction=0.25`는 하위 `ceil(표본 수 × 0.25)`개의 평균으로 근사하므로 기본 표본 6개에서는 하위 2개의 평균입니다. 실제 하위 25% 확률을 보장하는 값은 아닙니다.

현재 코어의 완전 지지·heavier-on-lighter 금지는 보수적인 규칙입니다. CoG는 정적 위치 대용 지표이며 실제 전도·마찰·접촉역학을 계산하지 않습니다. 연속 공간은 그리드 근사이고, 미래 순서의 스트레스 표본은 실제 발생 확률 추정이 아닙니다. 제한된 표본에서 계산한 CVaR도 통계적 꼬리 위험의 확정값은 아닙니다.

1차 연결에서는 버퍼 없는 AHEAD를 독립적으로 비교하고 선반 규칙 정책을 추가 비교합니다. 팔레트 교체 비용·교체 중 입고·부분 재배치·PPO 최적화는 인터페이스 뒤에서 확장할 수 있습니다. 현재 비교는 하나의 팔레트가 닫힐 때까지의 성능이며 전체 작업장 처리량으로 해석하지 않습니다.
